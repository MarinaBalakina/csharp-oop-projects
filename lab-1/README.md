# 🚆 Train Route Simulator

Проект на C#, моделирующий движение автоматического поезда по заданному маршруту.

Поезд проходит последовательность участков пути, может разгоняться и тормозить под действием силы, останавливаться на станциях и соблюдать ограничения скорости. Во время прохождения маршрута рассчитывается общее время поездки, а при невозможности продолжить движение возвращается причина неудачи.

## 📌 Основная идея

Маршрут состоит из нескольких типов участков, каждый из которых по-разному влияет на состояние поезда.

Во время движения учитываются скорость, ускорение, масса поезда и допустимая сила. Расчёт выполняется пошагово с заданным временным интервалом.

## Основные сущности

### Train

Поезд хранит:

- массу;
- текущую скорость;
- ускорение;
- максимально допустимую силу;
- временной шаг расчёта.

Он умеет рассчитывать время прохождения расстояния и изменять ускорение при приложении силы.

### Route Segment

Общий тип для всех элементов маршрута.

Каждый участок получает поезд, выполняет свою логику и возвращает результат прохождения.

### Plain Path

Обычный участок пути, на котором поезд продолжает движение с уже набранной скоростью без дополнительного ускорения.

### Powered Path

Силовой участок пути, воздействующий на поезд заданной силой.

Положительная сила разгоняет поезд, отрицательная — замедляет. Если сила превышает допустимое значение, участок не может быть успешно пройден.

### Station

Станция контролирует скорость прибывающего поезда.

Если скорость находится в допустимых пределах, к общему времени маршрута добавляется время посадки и высадки пассажиров. При превышении ограничения прохождение станции завершается неудачей.

### Route

Маршрут содержит последовательность участков и отвечает за их прохождение.

Время успешных участков суммируется, а после завершения маршрута дополнительно проверяется скорость поезда на финише.

### Result

Для передачи результата операций используются специальные Result-объекты.

Они позволяют хранить:

- статус выполнения;
- сообщение о причине неудачи;
- вычисленное значение, если оно необходимо.

## Тестирование

В проекте проверяются основные сценарии работы системы:

- успешное прохождение маршрута;
- превышение допустимой скорости на финише;
- успешное прохождение станции;
- превышение ограничения скорости на станции;
- последовательный разгон и торможение;
- невозможность движения без скорости и ускорения;
- ситуация, при которой торможение делает дальнейшее движение невозможным.
